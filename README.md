# MedTwin Dashboard Prototype

A polished, self-contained frontend demo for **MedTwin: AI-Powered Digital Twin System for Predictive Hospital Resource Management**.

Open `index.html` in any modern browser to present the interactive dashboard. No build step or server is required.

The prototype demonstrates:

- unified bed, oxygen, medicine, and staffing monitoring;
- a near-term resource forecast and actionable insight;
- priority alerts;
- a live hospital digital-twin flow map; and
- a simulated operational assistant, MedTwin Chat.
